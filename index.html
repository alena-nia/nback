How to play

N-Back is a memory exercise. Cues appear one at a time, and your job is to spot when the current cue is the same as the one a few steps earlier.

A single turn

Each turn, one square in the grid lights up. It can carry up to four cues at once:

  • Position — which square lit up
  • Number — the digit shown
  • Color — the digit's color
  • Sound — a spoken letter

What "N" means

N is how many turns back you compare against. At N = 2 you check whether the current cue matches the one from 2 turns ago.

Your job

When a cue matches the one N turns back, tap that cue's button (Position, Number, Color, or Sound). Each cue is judged on its own — the position can match while the color doesn't, so you might tap one button, several, or none in a turn. On a computer you can also use the keys A S D F.

Scoring & feedback

A correct tap flashes green; a wrong tap or a match you missed flashes red, and the ✓ / ✗ counter under the grid updates live. Your block score is the share of matches you caught, with false taps counting against you.

New to this? Start easy

It's meant to be hard. Build up gradually:

  1. Turn off every channel except one (say Position).
  2. Set N = 1.
  3. Play a few blocks, then raise N to 2, then add a second channel.

Two channels at 2-back is already genuinely challenging; all four at once is expert territory. There's no rush.

Settings

  • Channels — which cues are active
  • Steps back (N) — the difficulty
  • Pace — how fast turns go
  • Trials — how long a block is
  • Adaptive N — nudges N up after a near-perfect block

Everything is saved on your device only — nothing is uploaded.
